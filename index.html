旅行小抄

整理自官方或公開資料，價格與規定可能調整，出發前請再確認。
交通與車票
  • 維也納（2026 年起新制）：24 小時票 €10.20（App 數位版 €9.70）、7 日票 €28.90。48 與 72 小時票已在 2026/1/1 停售，天數不夠的話改買 7 日票或 24 小時票。
  • 紙本票要在上車前打印：地鐵站入口的藍色打票機，電車與公車則在車內打。打票前不算有效，查票會罰款。
  • WienMobil App 買的電子票是記名的，查票時要搭配有姓名的附照片證件（護照）。
  • 去機場超出市區核心區，要另外買票；機場快線 CAT 和機場巴士要向各業者另外買票。
  • 瑞士：上車前先買好票（SBB App 或車站售票機），搭車前沒票可能被罰款。
  • 瑞士通行證是否涵蓋某條景觀列車、是否要另付訂位費，請看官網。冰河快車、伯連納快車等需要訂位。
資料來源：Wiener Linien、維也納旅遊局官網。
小費與付款
  • 奧地利：餐廳帳單已含服務費，但習慣把帳單湊整或多給約 5–10%。付現時直接跟服務生說要付的總金額，不要把錢放在桌上。
  • 瑞士：服務費已含在價格裡，湊整即可，不給也不失禮。
  • 計程車通常也是湊整。
  • 刷卡時如果機器問要用歐元／瑞士法郎還是新台幣結帳，選當地幣別，不要選新台幣，通常匯率較差。
  • 信用卡大多通用，但市集、小咖啡館、山區的小店可能只收現金，帶一些零錢。
營業時間與休息日
  • 奧地利和瑞士大多數商店週日休息，車站、機場裡的商店和部分餐廳除外，週六就先補好需要的東西。
  • 有些博物館週一休館，排行程前先查官網。
  • 超市多半關得早，不要拖到晚上才買。
  • 山區的纜車和山屋有季節性，營運時間以公司官網為準。
退稅（持台灣護照可以申請）
  • 奧地利：單張發票 €75.01 以上。購物時要店員開退稅單（Tax Free form），並附原始發票。
  • 瑞士：同一家店單次購物 CHF 300 以上（含稅）。
  • 離境時要把商品（未使用）、發票、退稅單和護照拿給海關蓋章，沒有章就退不了。
  • 奧地利：購買後三個月內出口；瑞士：購買後 90 天內向海關驗證。
  • 如果在維也納機場離開歐盟，可以用電子驗證（DEV）蓋章，數位退稅單會被扣約 €4 手續費。
  • 退稅公司（如 Global Blue、Planet）會扣手續費，實拿比稅額少，常見在購物金額的 15% 以內。
  • 行程是瑞士到奧地利再回台灣：瑞士那段要先問店家和退稅公司怎麼蓋章，通常要在離開瑞士時處理。
  • 餐廳餐點和交通等服務通常不能退稅，只有可帶走的商品可以。
資料來源：奧地利財政部、奧地利經濟商會、瑞士聯邦稅務局、Planet 退稅公司。
插座與電壓
  • 奧地利是 F 型（圓形兩孔，C 型也通用），瑞士是 J 型（有三個孔的特殊形狀），電壓都是 230V。
  • 台灣的扁插頭不能直接用，帶一個含歐規插頭的轉接頭，兩國都要確認可用。
  • 吹風機、電捲棒等電器是不是 100–240V 的，先看機身標示，不是的話不要直接插。
  • 手機和相機充電器多半是 100–240V，只需要轉接頭。
飲水與廁所
  • 奧地利和瑞士的自來水都可以直接喝，街上的噴泉通常也有標示能不能喝。
  • 公共廁所常要收費，約 1 歐元或 1 瑞士法郎上下，火車站較常見，備一些零錢。
  • 餐廳點水時說 Leitungswasser，就是自來水，價格比瓶裝水便宜。

  • 謝謝：Danke（瑞士也常聽到 Merci）

  • 不好意思：Entschuldigung
  • 你會說英語嗎？：Sprechen Sie Englisch?
  • 我想要……：Ich hätte gern …
  • 請給我帳單：Die Rechnung, bitte／Zahlen, bitte
  • 多少錢？：Wie viel kostet das?
  • 廁所在哪裡？：Wo ist die Toilette?
  • ……在哪裡？：Wo ist …?
  • 不用找了：Stimmt so
  • 自來水：Leitungswasser
  • 救命！：Hilfe!
  • 我需要醫生：Ich brauche einen Arzt.
手機與 App
  • 網卡或 eSIM 要確認有涵蓋瑞士，瑞士不是歐盟。
  • 奧地利火車用 ÖBB App，瑞士火車用 SBB Mobile，維也納市區交通用 WienMobil。
  • 山區行程前，到纜車公司官網看當天營運公告和天氣。
  • 離線地圖先下載好，山區和隧道裡常沒有訊號。

護照遺失或被偷
  1. 先到最近的警察局報案，請他們開「護照遺失報案證明」。如果警察不開，就自己寫一份遺失護照說明書。
  2. 聯絡上面的台灣駐外館處：奧地利找維也納代表處，瑞士找伯恩代表團，人在瓦萊邦或日內瓦一帶找日內瓦辦事處。上班時間打一般電話，下班或很急就打緊急聯絡電話。
  3. 二選一：在當地申請補發新護照，所需文件由館處告知；或是趕著回國，就申請「入國證明書」返國，回台灣後再申請補發護照。
  4. 如果要搭機而護照不見了，入國證明書要先向館處申請，不能等到機場。
  5. 回台灣補發護照，官方資料寫約需 11 個工作天，以領事事務局公告為準。
  6. 手機裡先存好護照影本和身分證照片，能加快館處確認身分。
依據外交部領事事務局的護照補發說明，實際文件與流程以館處通知為準。
錢包或信用卡被偷
  1. 立刻用銀行 App 鎖卡，或打信用卡背面的海外客服電話（用國際電話，出發前先存好）。
  2. 到警察局報案，請他們開報案證明，旅平險理賠常會要。
  3. 改用備用卡和分開放的現金。
  4. 身上完全沒錢時，聯絡駐外館處說明狀況，詢問可以怎麼協助。
  5. 通知家人，請家人必要時協助聯絡銀行或匯款。
生病或受傷
  1. 危急時撥 112 或 144，說出所在地點。
  2. 不危急就先打旅平險的緊急救援專線（保單上有），請他們指引可就醫的醫院和是否需要先墊付。
  3. 保留診斷證明、收據、病歷，回台灣理賠要用。
  4. 重大傷病或住院時，聯絡駐外館處說明，詢問可否協助聯繫台灣家屬。
  5. 在山區受傷，先撥 112，瑞士可撥 1414 呼叫空中救援，奧地利山區可撥 140。直升機救援的費用可能很高，出發前要確認保險涵蓋。
行李遺失或延誤
  1. 不要離開機場，直接到行李櫃檯（Baggage Service）。
  2. 填寫行李異常報告（PIR），拿到案件編號，留好登機證和行李條。
  3. 留下住宿地址和電話，請航空公司把行李送到住宿。
  4. 延誤期間買的必需品留收據，向航空公司索賠，並向旅平險申請。
  5. 貴重物品和藥品一定要放隨身行李。
航班延誤或取消
  1. 先看航空公司 App 有沒有自動改簽，再到櫃檯或打客服。
  2. 向航空公司要書面或電子的延誤、取消證明，保險理賠需要。
  3. 從歐盟飛出，或搭歐盟航空公司飛抵歐盟的航班，可能適用歐盟的旅客權益規定，是否可以請求補償要看原因和延誤時間。
  4. 通知後面的住宿、火車與預約行程，改期或延後。
  5. 保留延誤期間的餐飲與住宿收據。
手機遺失或沒電
  1. 用另一個裝置到蘋果「尋找」或 Google「尋找我的裝置」鎖定手機。
  2. 打電信業者掛失 SIM，並鎖定銀行 App 和信用卡。
  3. 更改重要帳號密碼。
  4. 事先備份：行程截圖、離線地圖、住宿與車票 PDF，並把家人電話抄在紙上。
  5. 隨身帶行動電源。
錯過火車或景觀列車
  1. 先到車站服務櫃檯或問列車長能不能改搭下一班。
  2. 彈性票通常可以改搭同一路線的下一班，指定車次的特價票不一定可以，請當場問站務人員。
  3. 景觀列車需要訂位，錯過後通常要重新訂位。
  4. 接下來的纜車、住宿或預約行程，打電話或用 App 通知對方改時間。
  5. 行程之間預留轉乘緩衝，不要排太緊。
山區天氣突變或纜車停駛
  1. 出發前和當天早上查纜車公司官網或 App 的營運公告和天氣。
  2. 停駛就改走備案行程，不要冒險自己徒步下山。
  3. 迷路或受困：撥 112，瑞士也可撥 1414，保持保暖，留在原地，把手機定位分享給家人。
  4. 備好保暖衣物、水和行動電源。
遇到詐騙、扒手或搶劫
  1. 街頭有人拿請願書請你簽名、玩小遊戲或假裝幫忙，常是分散注意力，直接婉拒離開。
  2. 自稱便衣警察要檢查錢包或護照，請對方出示證件，並要求去警察局處理，不要當場交出物品。
  3. 被搶或受傷，先到人多的地方，撥 112 或當地警察電話。
  4. 報案取得報案證明，再鎖卡、通知館處，護照被偷參考上方的護照流程。
租車事故
  1. 人員有傷就先撥 112。
  2. 在安全的地方停車，開警示燈，拍下現場、車牌和雙方證件。
  3. 通知租車公司，並照租車合約的指示處理。
  4. 需要的話報警取得事故報告，保險理賠常會要。
重大災害或社會動盪
  1. 先照當地政府和旅館的指示行動。
  2. 查外交部的旅遊警示與旅外安全資訊，必要時聯絡駐外館處。
  3. 出發前到外交部網站「出國登錄」登錄行程，並下載外交部的「旅外安全指南」APP。
  4. 主動和台灣家人報平安。
